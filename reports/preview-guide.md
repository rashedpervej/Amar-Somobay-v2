# লাইভ প্রিভিউ — কীভাবে দেখবেন

**তারিখ:** ৩১ অক্টোবর ২০২৬ · **শাখা:** `arena/050e88aa-amar-somobay-v2`

## ১ · প্যানেল = আসল অ্যাপ

Arena-র **Live Preview** প্যানেলের ভেতরেই Vite অ্যাপ চলছে (`:5173`)। এটি কোনো স্ক্রিনশট বা মকআপ নয়।
প্যানেলের উপরের ডান কোণে **⤢ / Open** থাকলে চাপলে পুরো পর্দায় দেখা যায়।

> `https://<port>-<sandbox>.e2b.app` সরাসরি নতুন ট্যাবে খুললে E2B **“Missing traffic access token” (403)** দেয়। এটি স্যান্ডবক্সের নিরাপত্তা; প্যানেলের বাইরে পাবলিক লিংক এখনো কাজ করে না।

## ২ · শুরুর পর্দা (`/`)

`/` এখন **“আমার সমবায় — লাইভ ডেমো”** লঞ্চার — তিনটি বড় কার্ড:

| কার্ড | রুট | কিসের জন্য |
|---|---|---|
| সদস্য অ্যাপ | `/m/home` | মোবাইল-অনলি (৩৬০–৪৩০px) |
| অ্যাডমিন মোবাইল | `/a/home?role=MANAGER` | মোবাইল-ফার্স্ট |
| অ্যাডমিন ওয়েব | `/w/dashboard` | ডেস্কটপ (১২৮০px+) |

## ৩ · কোনটা কোথায় দেখবেন

- **ফোনে:** সদস্য অ্যাপ বা অ্যাডমিন মোবাইল খুলুন। এগুলোই মোবাইলের জন্য ডিজাইন করা।
- **ডেস্কটপে:** অ্যাডমিন ওয়েব। ফোনে খুললে টেবিল ছোট দেখাবে — এটি ব্যর্থতা নয়, Admin Web ইচ্ছাকৃতভাবে ডেস্কটপ-শুধু।
- **রিফ্রেশ:** সব ডেটা ইন-মেমরি ডেমো — রিফ্রেশে সিডে ফেরে; কোনো DB লেখা হয় না।

## ৪ · দ্রুত পরীক্ষার পথ

1. `/` → সদস্য অ্যাপ → সঞ্চয় → জমা → রসিদ
2. `/a/home?role=MANAGER` → অনুমোদন কিউ → একটি অনুমোদন
3. `/w/qh` → পণ্য → নিয়ম → Simulation → আবেদন কিউ → সিদ্ধান্ত → OTP বিতরণ (`123456`) → পরিশোধ → সনদ
4. `/w/qh/arrears` → write-off; `/w/qh/reports` → read-only রিপোর্ট

## ৫ · ডেমোর সীমা

- OTP: `123456` (প্রকৃত SMS যায় না)
- CSV/PDF/প্রিন্ট: শুধু “ডেমো” বার্তা
- সদস্য `m7`/`m9`-এর নাম নেই — আইডি দেখায়
- কোনো ডিপ্লয়, DB মাইগ্রেশন বা `main` মার্জ হয়নি

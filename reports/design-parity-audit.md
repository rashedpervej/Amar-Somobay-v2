## ১ · উদ্দেশ্য ও পদ্ধতি

প্রোটোটাইপ (`prototype/assets/ui.css`, `skins.css`, `screens.js`) হলো একমাত্র ডিজাইন-সোর্স। এই অডিটে ২০৫টি ইনভেন্টরি পর্দা ও অ্যাপের ২১৭টি `src/apps/**/*.tsx` ফাইল যাচাই করা হয়েছে — **রঙ, ফন্ট, স্পেসিং, কর্নার-রেডিয়াস, কার্ড, বোতাম, ইনপুট, চিপ, KPI ও টেবিল**।

পদ্ধতি (পুনরায় চালানো যায়):

```bash
cd app
node tools/design-parity.mjs --csv ../reports/audit/design-parity-matrix.csv
```

স্ক্রিপ্ট চারটি স্তর যাচাই করে:

1. **টোকেন**: `prototype/assets/ui.css`-এর `:root` বনাম `app/src/styles/tokens.css` — প্রতিটি সাধারণ ভেরিয়েবলের মান অক্ষরে অক্ষরে।
2. **কম্পোনেন্ট স্পেক**: `.card / .btn / .chip / .inp / .kpi / .tbl` বনাম `.s-card / .s-btn / .s-chip / .s-inp / .s-kpi / .s-tbl` (রেডিয়াস, প্যাডিং, ফন্ট-সাইজ, ছায়া, বর্ডার)।
3. **সোর্স স্ক্যান**: কাঁচা hex, নন-ল্যাটিন অক্ষর, ফন্ট-ওভাররাইড, অপরিচিত Tailwind শেড, arbitrary রেডিয়াস, ৪৮px-এর কম ট্যাপ-টার্গেট।
4. **প্রতি-ফাইল ম্যাট্রিক্স**: `reports/audit/design-parity-matrix.csv` (২১৭ সারি)।

## ৪ · এই অডিটে যা সংশোধন করা হলো

1. **নতুন `src/styles/ds.css`** — প্রোটোটাইপের `.card/.btn/.chip/.inp/.kpi/.tbl` ব্লকের মান `@layer components`-এ হুবহু কপি; `tokens.css`-এর মান অপরিবর্তিত।
2. **শেয়ার্ড প্রিমিটিভ** (`components/ui.tsx`, `components/form.tsx`) এখন ওই ক্লাস ব্যবহার করে — ফলে **সব ২০৫ পর্দায়** কার্ড/বোতাম/চিপ/KPI/টেবিল/ইনপুটের রেডিয়াস, প্যাডিং ও ফন্ট একসাথে প্রোটোটাইপের মানে এসেছে। আগে বোতাম ছিল ১২px রেডিয়াস/১৬px ফন্ট, কার্ড ১৬px রেডিয়াস — প্রোটোটাইপের ১৫px/১৫.৫px ও ২২px নয়।
3. **অপরিচিত শেড**: `bg-green-50` (Reconciliation নির্বাচিত সারি) → `bg-green-050`; `border-green-200` (লঞ্চার) → `border-green-100`। Tailwind-এর ডিফল্ট সবুজ এখন আর লিক করে না।
4. **৯px ফন্ট** (৩টি ফাইল) → ১০px; প্রোটোটাইপে ৯px নেই।
5. **ট্যাপ-টার্গেট**: “অবদান”, “বিস্তারিত”, “সব দেখুন”, “পরিশোধ”, “অডিট লগ” ইনলাইন লিংক এবং সম্পাদনা/সরান আইকন বোতামে `min-h-10`/`min-h-tap`; তালিকা-সারির বোতামে স্পষ্ট `min-h-tap`।
6. **`Field` লেবেল** 13.5px/600 + 15px নিচে মার্জিন (প্রোটোটাইপ `.field`), ইনপুট `s-inp`।

সংশোধনের পর: `tsc` ০ ত্রুটি · `npm test` **৬৭০/৬৭০** · build সফল · `ALL_ROUTES_RENDER`।

## ৫ · অবশিষ্ট পার্থক্য (সচেতন, লুকানো নয়)

- **ফন্ট-সাইজ**: ১২৪টি arbitrary `text-[Npx]` আছে; প্রতিটির মান প্রোটোটাইপেই আছে (১০, ১১, ১৩, ১৫, ২১, ২৯, ৩০, ৩২px)। প্রোটোটাইপের স্ক্রিন-লেভেল inline সাইজ (১৩.৬, ১৩.৪, ১২.৬, ১২.৪px) টোকেনে (১৪/১২px) নিকটতম মানে ম্যাপ হয়েছে — হুবহু ভগ্নাংশ পুনরুত্পাদন করা হয়নি।
- **হিরো গ্রেডিয়েন্ট**: কিছু পর্দায় `green-800 → green-700` গ্রেডিয়েন্ট হাতে লেখা; প্রোটোটাইপের হিরো-ব্লকের মতোই, কিন্তু ভবিষ্যতে একটি `.s-hero` ক্লাসে কেন্দ্রীভূত করা যায়।
- **অ্যাডমিন ওয়েব লেআউট**: `/w/*` ডেস্কটপ সাইডবার-লেআউট ব্যবহার করে, প্রোটোটাইপের মোবাইল-ফ্রেম নয় — এটি আপনার অমীমাংসিত সিদ্ধান্ত।
- **ভিজ্যুয়াল স্ক্রিনশট তুলনা সম্ভব নয়**: স্যান্ডবক্সে ব্রাউজার নেই; তাই কম্পিউটেড-স্টাইল নয়, সোর্স + টোকেন + SSR রেন্ডার দিয়ে যাচাই। পিক্সেল-ডিফ তুলনার জন্য ব্রাউজারযুক্ত পরিবেশ দরকার।

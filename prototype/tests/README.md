# prototype/tests — প্রোটোটাইপ যাচাই হার্নেস

সব হার্নেস jsdom ব্যবহার করে (ব্রাউজার লাগে না)। **ব্যতিক্রম:** jsdom লেআউট ইঞ্জিন চালায় না, তাই প্রকৃত পিক্সেল মাপার জন্য `prototype/mobile-check.html` আসল ব্রাউজারে/ফোনে চালাতে হয় (ধাপ E)।

উৎপন্ন ফাইল: `mobile-contract.md` (প্রতি-পর্দা ছক, `tmc.mjs` প্রতি রানে হালনাগাদ করে) ও `mobile-contract-states.json` (MC-14 স্টেট-স্ন্যাপশট — ইচ্ছাকৃত বদল হলে মুছে দিলে নতুন বেসলাইন তৈরি হয়)। প্রথমবার চালাতে:

```sh
cd prototype/tests && npm i jsdom     # node_modules স্ন্যাপশটে সংরক্ষিত হয় না
node --max-old-space-size=3072 t.mjs  # এরপর একে একে বাকিগুলো
```

`baseline-ui.css` = স্কিন-অডিটের তুলনা-ভিত্তি। **ধাপ A + B + C + D** পর্যন্ত হালনাগাদ করা আছে
(ধাপ A: ব্যাকবাটন ৪৪px, `.amrole.cmp`, `.amhead.deep`, `.flowbar`, শিট টগল, `.amact` ·
ধাপ B: `.mrows`/`.row-amt`, `.xtbl tbody tr{cursor:default}` ·
ধাপ C: `.btn-sm` ৪৪px, `.chip-btn` ৪০px, `.iconbtn` ৪৪px, সেগমেন্ট/ট্যাব ৪৪px, `.decbar .btn` ৪৮px,
`.acc2-b` টগল, `.foldgrp`, `.sh-filter` ·
ধাপ D: `.filepick`/`.filebtn`/`.filenote`, `.offq`, `.radios`/`.radio-card`/`.rc-*`, `a.telink`)।
ui.css ইচ্ছাকৃতভাবে বদলালে: `cp ../assets/ui.css baseline-ui.css`

**নতুন গ্লোবাল ফাংশন (screens.js):** `mrows(rows,o)` প্যাটার্ন ৭ মোবাইল তালিকা · `amAct(btn,kind)` ও
`amActAuto(btn)` অ্যাকশন শিট · `amSheetToggle(btn)` স্ক্রিনের নিজস্ব শিট · `foldToggle(btn)` ভাঁজ ·
`amFile(label,o)` / `amFilePicked(input)` ফাইল-পিকার · `amOffq()` অফলাইন ব্যাজ · `amRadios(items,name,o)`
রেডিও-কার্ড · `telHref/telLink/collectorMobile` ফোন-লিঙ্ক। সবগুলোই `window.*`-এ এক্সপোর্ট করা,
কারণ jsdom `runScripts:'outside-only'` মোডে inline `onclick` চলে না — হার্নেসে ফাংশন সরাসরি কল করতে হয়।

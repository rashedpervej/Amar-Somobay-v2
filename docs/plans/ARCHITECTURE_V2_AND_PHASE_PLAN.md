**তিনটি অলঙ্ঘনীয় নীতি**
1. **এক ব্যাকএন্ড, এক নিয়ম** — UI তিনটি, লজিক একটাই। Mobile ও Web-এ ব্যবসায়িক আচরণ আলাদা হওয়া অসম্ভব, কারণ সিদ্ধান্ত সার্ভারে।
2. **UI = authorization নয়** — ভূমিকা সবসময় `organization_members` (+ `platform_admins`) থেকে; বোতাম লুকানো নিরাপত্তা নয় (X2/M7)।
3. **ডিজাইন = প্রোটোটাইপ** — পুরনো অ্যাপের রং/ফন্ট/স্পেসিং/কম্পোনেন্ট নতুন অ্যাপে প্রবেশ করবে না; পুরনো **ফিচার** নতুন রূপে বাঁচবে।
